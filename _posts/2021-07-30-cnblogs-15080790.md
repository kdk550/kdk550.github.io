## 说明/提示

对于<span class="katex"><span class="katex-mathml">100\%<span class="katex-html"><span class="base"><span class="strut"><span class="mord">1<span class="mord">0<span class="mord">0<span class="mord">%的数据，对于全部数据， <span class="katex"><span class="katex-mathml">1 \leq N \leq 39<span class="katex-html"><span class="base"><span class="strut"><span class="mord">1<span class="mspace"><span class="mrel">≤<span class="mspace"><span class="base"><span class="strut"><span class="mord mathnormal">N<span class="mspace"><span class="mrel">≤<span class="mspace"><span class="base"><span class="strut"><span class="mord">3<span class="mord">9 且 <span class="katex"><span class="katex-mathml">N<span class="katex-html"><span class="base"><span class="strut"><span class="mord mathnormal">N 为奇数。</span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span></span>

**直接模拟**

**需要开二维数组，1的位置需要特判**



```

```



**for循环套if语句判断就行**

**完整代码（4个条件判断是按顺序的我不喜欢压行）：**



```
//洛谷P2615 [NOIP2015 提高组] 神奇的幻方 题解
#include<iostream>
using namespace std;
int N[40][40];
int n;
int main()
{
    cin >> n;
    N[1][(n+1)/2] = 1;
    int x = 1;
    int y = (n + 1) / 2;
    for (int i = 2; i <= n*n; i++)
    {
        if (x == 1 && y != n)
        {
            x = n;
            y = y + 1;
            N[x][y] = i;
            continue;
        }

        if (y == n && x != 1)
        {
            x=x-1;
            y = 1;
            N[x][y] = i;
            continue;
        }

        if (x == 1 && y ==n)
        {
            x=x+1;
            N[x][y] = i;
            continue;
        }

        if (x != 1 && y != n && N[x - 1][y + 1] == 0)
        {
            x--;
            y++;
            N[x][y] = i;
            continue;
        }
        else
        {
            x++;
            N[x][y] = i;
            continue;
        }
    }
    

    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            cout << N[i][j]<<" ";
        }
        cout << endl;
    }
    return 0;
}
```
